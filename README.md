
# StudyPlanner

A simple Python console application for organizing study tasks
and tracking study progress.

## Features

- Add tasks with a subject and description
- View all study tasks
- Mark tasks as completed
- Delete tasks
- Track completed and pending tasks
- Calculate task completion percentage
- Save tasks between sessions using JSON

## Technologies Used

- Python 3
- JSON for data storage
- File handling
- Lists and dictionaries
- Functions and loops

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

       python study_planner.py

   On some systems, use:

       python3 study_planner.py

## Data Storage

Tasks are stored in `study_tasks.json`, which is created
automatically when tasks are saved.

Keep this file in the same folder as the Python program.

## Learning Outcomes

This project demonstrates functions, lists, dictionaries,
file handling, JSON, exception handling, and menu-driven
programming.
